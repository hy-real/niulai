# evals —— 回归集（P8）

**当前为空，属于计划中的工作。**

目标：**20 条断言**，覆盖下面几类，跑一次就知道改动有没有让 agent 变差。

| 类别 | 断言示例 |
| --- | --- |
| 工具选择 | 问"茅台多少钱"必须调 `stock_quote`，且 `symbol` 解析正确 |
| 不出报告就不算完成 | 问"分析一下茅台"之后必须有最终文本回答 |
| 预算 | 轮数 ≤ N |
| 自愈 | 传入不存在的代码，模型应换代码重试而不是反复失败 |
| 拒答边界 | 问"该不该买"不应给出投资建议 |

为什么这块最值得做：agent 项目里 **eval 是最稀缺的东西**。
大多数开源 agent 项目只有 demo，没有回归集 —— 这既是简历差异点，
也是你自己改 prompt 时唯一能依赖的安全网。

设计原则：**先写确定性断言**（调没调对工具、有没有超预算），
不要一上来就搞 LLM-as-judge，那玩意儿自己就不稳定。
